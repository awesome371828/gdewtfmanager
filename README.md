# GDE.WTF — бот проекта для Telegram

Бот проекта [GDE.WTF](https://gde.wtf/) помогает управлять Telegram-сообществами: модерация, предупреждения, статистика участников, настройки чата и инструменты для команды проекта.

## Что умеет бот

- Модерация участников: предупреждения, муты, баны, удаление сообщений и история действий.
- Статистика активности, профили, рейтинги и списки администраторов.
- Настройки и инструменты управления Telegram-группами.
- Интеграция с внешним API модераторов GDE.WTF через команды с префиксом `!`.
- Хранение настроек и данных в PostgreSQL на Relax Dev.

Сайт проекта: https://gde.wtf/

## Развёртывание

Основной файл приложения — `iris.py`. Бот рассчитан на постоянный процесс на Relax Dev и использует переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
- `DATABASE_URL` — строка подключения к PostgreSQL из переменных проекта Relax Dev (TLS отключён на внутреннем адресе).
- `BOT_OWNER_ID` — Telegram ID владельца/оператора интеграции.
- `GDEWTF_API_KEY` — ключ внешнего API GDE.WTF, если включена интеграция.
- `GDEWTF_API_BASE` — необязательный адрес API; по умолчанию `https://map.gde.wtf/api/ext`.

GitHub Actions для запуска бота не используется. На хосте должен работать ровно один экземпляр с этим Telegram-токеном.

Не добавляйте токены и ключи в исходный код, коммиты или публичные сообщения.

## База данных

Файл `schema.sql` содержит таблицы и функции PostgreSQL, используемые ботом. Перед изменениями схемы сделайте резервную копию базы. Не удаляйте таблицы, пока не проверили, что текущая версия приложения и сохранённые данные от них не зависят.

## Команды

В Telegram доступны `/start`, `/help`, `/commands` и команды модерации/статистики. Подробный перечень можно получить в меню самого бота. Команды интеграции GDE.WTF с префиксом `!` доступны только пользователям, которым разрешён доступ к внешнему API.
